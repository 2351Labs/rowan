# Using Rowan from React

The custom element is the product. `@rowan-ui/core/react/button` is a generated wrapper around `rowan-button`. It is not a second implementation.

```tsx
import { RowanButton } from "@rowan-ui/core/react/button";

<RowanButton onRowanClick={() => save()}>Save</RowanButton>;
```

The same control as a tag:

```tsx
import { useEffect } from "react";

useEffect(() => {
  void import("@rowan-ui/core/button");
}, []);

<rowan-button>Save</rowan-button>;
```

Prefer the wrapper in React. `onRowanClick` maps to `rowan-click`. `ref` is the host element. Named slots stay `slot="..."`. Import wrappers from a client component; they load the element module and are not Server Components. Objects, arrays, and events are wrapper props — not attributes on the tag.

Do not hand-edit files under `src/react/generated/` — `npm run analyze` regenerates them from the Custom Elements Manifest.

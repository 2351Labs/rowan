# React

Rowan is a Web Component library. `@rowan-ui/core/react` adds JSX types and `useRowanElement()`. It does not ship React wrappers and it does not register elements.

Three steps:

1. **Register on the client.** Custom-element modules define the tag as a side effect. Import them in `useEffect` (or another browser-only boundary), never at the top of a Server Component.
2. **Scalars in JSX.** Strings and numbers such as `label` and `name` can be attributes.
3. **Objects, arrays, and events through the hook.** `useRowanElement(ref, { properties, events })` assigns property-only APIs and binds native `addEventListener` handlers.
